# Challenge Mode

> Status: Future

Puzzle levels with specific objectives.

## Concept

- Each challenge has unique rules and win conditions
- Not just "break all bricks"
- Brain-teaser layouts

## Example Challenges

| # | Name | Objective |
|---|------|-----------|
| 1 | One Shot | Clear all bricks with a single launch |
| 2 | No Bounce | Clear without hitting side walls |
| 3 | Speed Run | Clear in under 10 seconds |
| 4 | Minimalist | Only 3 bricks, but tricky angles |
| 5 | Gauntlet | Navigate through a gap in a wall |
| 6 | Zen | Break exactly N bricks, no more |

## Unlocking

- Challenges unlock sequentially
- Some require specific scores in classic mode
