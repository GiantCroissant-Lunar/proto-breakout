# Arkanoid Successors — Innovations Beyond the Original

## Arkanoid: Revenge of Doh (1987)

### New Brick Types

| Brick Type | Behavior | Visual |
|------------|----------|--------|
| **Notched Silver** | Regenerates after being destroyed (on a timer) | Silver with notch pattern |
| **Moving Brick** | Slides left/right when unobstructed | Distinct animated texture |
| **Warp Brick** | Triggers level-skip warp gate | Glowing/hyper texture |

### New Mechanics
- **Warp Gates:** Choose your path through stages (branching level select)
- **Regenerating bricks:** Adds time pressure — must clear level quickly
- **Moving bricks:** Changes shot angles dynamically
- **2-player alternating:** Competitive play

## DX-Ball 2 (1998, PC)

### Brick Innovations

| Brick Type | Behavior |
|------------|----------|
| **Multi-Hit (visual)** | Cracks/damage shown progressively |
| **Invisible** | Only visible when ball is near |
| **Explosive** | Chain reaction — destroys neighbors |
| **Poison** | Harmful power-up (shrinks paddle, speeds ball) |
| **Magic Eye** | Reveals invisible bricks |
| **Chain** | All connected same-color bricks explode |

### Game Structure
- **150+ boards** across themed board sets
- Board sets have visual themes (space, nature, etc.)
- Custom board editor for user-created levels

## Modern Brick-Breaker Innovations (post-2000)

### Shatter (2010)
- **3D physics:** Curved brick surfaces affect ball trajectory
- **Brick shattering:** Physics-based debris particles
- **Boss bricks:** Large multi-hit bricks with attack patterns

### Breakout: Recharged (2022)
- **Power-up chaining:** Stack multiple power-ups simultaneously
- **Challenge mode:** Time-attack and score-attack variants
- **Arcade roots:** Faithful to original Breakout simplicity

### Common Modern Patterns
- **Procedural generation** for endless mode
- **RPG elements:** Persistent upgrades between runs
- **Visual feedback:** Particle effects, screen shake, combo counters
- **Accessibility:** Adjustable difficulty, colorblind modes

## Design Takeaways for proto-breakout

### From Arkanoid (Essential)
- Multi-hit bricks with progressive difficulty
- Indestructible obstacles for layout variety
- Power-up capsules from special bricks
- ~30+ unique stage layouts

### From Revenge of Doh (Nice to Have)
- Regenerating bricks for time pressure
- Moving bricks for dynamic layouts
- Branching path / level select

### From DX-Ball 2 (Advanced)
- Explosive chain-reaction bricks
- Invisible bricks for surprise
- Visual damage states (cracks)
- Themed stage sets

### From Modern Games (Polish)
- Particle effects on brick destruction
- Combo counter / multiplier
- Screen shake on impact
- Colorblind-safe palette
